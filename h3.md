- Heinonen 2026: How to Install Linux to Virtualbox?

- Karvinen 2020: Command Line Basics Revisited
    - Linux commands can be used to navigate directories and manage files
    - SSH allows secure remote access to another computer
    - sudo provides administrator privileges when needed
    - **My own thought**: Using the command line can be faster than doing the same tasks through a graphical interface when you get familiar with it
- Karvinen 2022: Cracking Passwords with Hashcat
    - Hashcat is a tool used to crack password hashes using methods such as dictionary attacks
    - Hashcat needs to know the hash type, for example MD5, before cracking
    - GPU processing can significantly speed up password cracking
    - **My own thought**: This shows why using common passwords is risky, even when passwords are stored as hashes
