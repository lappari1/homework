## x) Read and summarize (with some bullet points; check tips for free access)

- [Applied Cryptography: Protocols, Algorithms and Source Code in C, 20th Anniversary Edition, Chapter 1.1 Terminology](https://learning.oreilly.com/library/view/applied-cryptography-protocols/9781119096726/08_chap01.html#chap01-sec001)
    - Encryption converts plaintext into ciphertext, while decryption converts it back into the original message
    - Cryptography aims to protect confidentiality, but it can also provide authentication, integrity and nonrepudiation
    - Modern cryptography relies on keys rather than keeping algorithms secret. Algorithms should be publicly known and tested
    - Symmetric encryption uses the same (or closely related) key for encryption and decryption, while public-key encryption uses separate public and private keys
    - Cryptanalysis attempts to break encryption through different attack methods. Strong cryptographic algorithms rely on public scrutiny and should remain secure even if the algorithm itself is known

 - [Applied Cryptography: Protocols, Algorithms and Source Code in C, 20th Anniversary Edition, Chapter 2.5 Communications Using Public-Key Cryptography](https://learning.oreilly.com/library/view/applied-cryptography-protocols/9781119096726/10_chap02.html#chap02-sec005)
    - Public-key cryptography allows people to communicate securely without having to exchange a secret key beforehand
    - It makes secure communication easier between people who have not previously established a secure connection
    - Different encryption methods are often combined to balance security and performance
    - Secure communication depends on protecting the keys and limiting the risks associated with their exposure

- [Karvinen 2023: PGP - Send Encrypted and Signed Message - gpg](https://terokarvinen.com/2023/pgp-encrypt-sign-verify/)
    - PGP allows users to send encrypted messages over untrusted networks, protecting the confidentiality of the messages
    - Public key verification is important to ensure that a public key belongs to the intended recipient and to prevent impersonation
    - Encryption and digital signatures provide confidentiality, authentication and integrity for messages

## c) Password management. Demonstrate use of a password manager. What kind of attacks take advantage of people not using password managers?

I used KeePassXC as a password manager. I created a new password database protected with a master password and added a sample account. I also tested the built-in password generator, which creates strong and random passwords.

Password managers help users create and store unique passwords for different services. Not using a password manager can increase the risk of several types of attacks:

- Brute-force attacks: Attackers try different password combinations to find the correct one. Weak and short passwords are easier to crack.

- Dictionary attacks: Attackers use lists of common words and passwords to guess login credentials.

- Password spraying: Attackers try a few common passwords against multiple user accounts.

Using a password manager makes these attacks harder by allowing users to generate and use long, strong and unique passwords for every service. It also prevents password reuse, which reduces the risk of attackers accessing multiple accounts with leaked credentials.

Sources:
- [MITRE ATT&CK - Password Spraying](https://attack.mitre.org/techniques/T1110/003/)
- [NIST - How Do I Create a Good Password?](https://www.nist.gov/cybersecurity-and-privacy/how-do-i-create-good-password)
